# TaskFlow

A simple task management system built in Java.

## Requirements

- Java 8 or higher
- (see lib/ folder)

## Setup

1. Clone the repository
2. Configure the `config/config.properties` file
3. Compile and run

## Compiling

You can compile the project with javac. Refer to your IDE or the course notes for the exact command for your operating system.

Or use your preferred IDE (VS Code with the Java Extension Pack is recommended).

## Running

The program has a main entry point somewhere in the codebase — part of the activity is locating it.

## Notes

- Logging output goes to console
- Tasks are stored in memory (no database required... probably)
- There is a dependency on an external utility — check the `lib/` folder and make sure the classpath is set up
